54. MAP INITIALIZATION
--------------------------------------------------

Use a Leaflet map similar to:

const map = L.map('map').setView([LATITUDE, LONGITUDE], 13);

L.tileLayer(
  'https://tile.openstreetmap.org/{z}/{x}/{y}.png',
  {
    attribution:
      '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors'
  }
).addTo(map);

Do not use a hard-coded London location such as:

[51.505, -0.09]

That is only an example.

The actual center should be dynamically determined from the
resolved land-record location.

If the parcel cannot be resolved, use the selected
village/district location if available and clearly display:

"Parcel boundary unavailable — showing reference location."

58. AUTOMATIC MAP FOCUS
--------------------------------------------------

When the user reaches the GIS section after document extraction:

1. Read the extracted location.
2. Resolve it against the demo/reference GIS dataset.
3. If a matching parcel exists:
   - center the map
   - zoom to the parcel
   - display marker
   - display parcel boundary
   - open the parcel information panel

The map should feel like:

"AI found the land described in the document."

Do not make the user manually search for the parcel again
when the system already has a successful match.

60. LOCATION RESOLUTION STATES
--------------------------------------------------

Handle three scenarios.

CASE 1 — EXACT DEMO PARCEL MATCH

✓ Parcel located

"Matching reference parcel found for Dag/Khasra 125/2."

Show:
- marker
- polygon
- parcel information

CASE 2 — LOCATION FOUND, PARCEL NOT FOUND

⚠ Location identified

"Village/district location found, but the specific parcel
could not be matched in the available reference dataset."

Show:
- approximate/reference location
- no false parcel boundary

CASE 3 — LOCATION CANNOT BE RESOLVED

⚠ Location unavailable

"Insufficient location information to locate this record."

Show:
- extracted location fields
- missing fields
- manual search option

NEVER invent coordinates for a parcel.

"OpenStreetMap confirms the legal boundary."

"Map base: OpenStreetMap"

"Parcel information: BhuVerify demo/reference cadastral data"

"Ownership information: extracted/reference land records"

This distinction must be visible in the UI.

--------------------------------------------------

   - Owner
   - Village

   vs
   Reference GIS Area

   "Potential area discrepancy."

   "View Verification"
